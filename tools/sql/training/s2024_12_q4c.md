  EXAM(ExamID, Subject, Level, TotalMarks)
  EXAM_QUESTION(ExamQuestionID, ExamID, QuestionNumber, Question, MaxMark)
prompt: |
  Each question belongs to exactly one exam, but Exam_Question.ExamID is not yet linked
  to the Exam table. Using **ALTER TABLE**, add a foreign key so that ExamID must exist
  in Exam.
seed: |
  CREATE TABLE Exam (
    ExamID VARCHAR(6) PRIMARY KEY,
    Subject VARCHAR(30),
    Level VARCHAR(10),
    TotalMarks INTEGER
  );
  CREATE TABLE Exam_Question (
    ExamQuestionID INTEGER PRIMARY KEY,
    ExamID VARCHAR(6),
    QuestionNumber INTEGER,
    Question VARCHAR(200),
    MaxMark INTEGER
  );
answer: |
  ALTER TABLE Exam_Question ADD FOREIGN KEY (ExamID) REFERENCES Exam(ExamID);
wrong: |
  ALTER TABLE Exam_Question ADD FOREIGN KEY (ExamQuestionID) REFERENCES Exam(ExamID);
