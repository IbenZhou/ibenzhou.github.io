title: Store each photograph's resolution
marks: 2
difficulty: basic
source: 同构于 2022 冬季 P13 Q2(d)
coverage: ALTER TABLE, VARCHAR
schema: |
  PHOTOGRAPH(PhotoID, TelescopeID, DateTaken, TimeTaken, Elevation)
prompt: |
  Each photograph needs to record its resolution in the form `1920 x 1068`. Using
  **ALTER TABLE**, add one field called **Resolution** to Photograph that can store a
  value of that shape.
seed: |
  CREATE TABLE Photograph (
    PhotoID INTEGER PRIMARY KEY,
    TelescopeID INTEGER,
    DateTaken DATE,
    TimeTaken TIME,
    Elevation REAL
  );
answer: |
  ALTER TABLE Photograph ADD COLUMN Resolution VARCHAR(20);
wrong: |
  ALTER TABLE Photograph ADD COLUMN Resolution INTEGER;
check: schema
checktable: Photograph
