title: Repair a broken counting query

source: 同构于 2023 夏季 P12 Q2(c)(iii)
coverage: SELECT, COUNT, INNER JOIN, WHERE
schema: |
  STUDENT(StudentID, FirstName, LastName, RiderLevel, PreferredHorseID)
  LESSON(LessonID, Date, Time, StudentID, HorseID, LessonContent)
prompt: |
  The query below was meant to return the **number of riders** whose level is
  **beginner** and who have a lesson booked on **09/09/2023**, named NumberOfRiders.
  It is wrong in several ways. Write the **corrected** query.

  ```
  SELECT SUM(STUDENT.RiderLevel) AS NumberOfRiders
  FROM STUDENT, LESSON
  WHERE StudentID = StudentID
  OR Date = #09/09/2023#
  AND STUDENT.RiderLevel = Beginner;
  ```
seed: |
  CREATE TABLE Student (
    StudentID INTEGER PRIMARY KEY,
    FirstName VARCHAR(30),
    LastName VARCHAR(30),
    RiderLevel VARCHAR(15),
    PreferredHorseID INTEGER
  );
  CREATE TABLE Lesson (
    LessonID INTEGER PRIMARY KEY,
    Date DATE,
    Time TIME,
    StudentID INTEGER REFERENCES Student(StudentID),
    HorseID INTEGER,
    LessonContent VARCHAR(40)
  );
  INSERT INTO Student VALUES
    (1, 'Ivy', 'Chen', 'beginner', 1),
    (2, 'Omar', 'Haddad', 'beginner', 2),
    (3, 'Rui', 'Sato', 'intermediate', 3);
  INSERT INTO Lesson VALUES
    (10, '2023-09-09', '09:00', 1, 1, 'trotting'),
    (11, '2023-09-09', '10:00', 2, 2, 'mounting'),
    (12, '2023-09-09', '11:00', 3, 3, 'canter'),
    (13, '2023-09-16', '09:00', 2, 2, 'trotting');
answer: |
  SELECT COUNT(Student.StudentID) AS NumberOfRiders
  FROM Student
  INNER JOIN Lesson ON Student.StudentID = Lesson.StudentID
  WHERE Lesson.Date = '2023-09-09' AND Student.RiderLevel = 'beginner';
wrong: |
  SELECT SUM(Student.RiderLevel) AS NumberOfRiders
  FROM Student, Lesson
  WHERE Student.StudentID = Student.StudentID
  OR Lesson.Date = '2023-09-09'
  AND Student.RiderLevel = 'beginner';
check: rows
