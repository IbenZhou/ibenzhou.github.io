  For the observer with the ID **J_123**, return the **size** of each bird and the

  CREATE TABLE Bird_Type (
    BirdID CHARACTER(4) PRIMARY KEY,
    Name VARCHAR(30),
    Size VARCHAR(10)
  );

    SeenID INTEGER PRIMARY KEY,
    BirdID CHARACTER(4) REFERENCES Bird_Type(BirdID),
    Date DATE,
    Location VARCHAR(30),
    PersonID VARCHAR(6)
  );

answer: |
  SELECT Bird_Type.Size, COUNT(Bird_Type.BirdID) AS NumberOfBirds
  FROM Bird_Type
  INNER JOIN Bird_Seen ON Bird_Type.BirdID = Bird_Seen.BirdID
  WHERE Bird_Seen.PersonID = 'J_123'
  GROUP BY Bird_Type.Size;
