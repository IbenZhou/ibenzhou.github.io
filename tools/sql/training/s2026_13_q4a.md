prompt: |
  The script below was meant to create the table **Subject**. It contains **four**
  errors. Write the corrected CREATE TABLE statement.

  ```
  01 CREATE DATA BASE SCHOOLDATA;
  02 CREATE TABLE SUBJECT(
  03    SubjectCode VARCHAR NONULL,
  04    SubjectName VARCHAR
  05    DepartmentID VARCHAR,
  06    PRIMARY KEY (SubjectCode),
  07    FOREIGN KEY (DepartmentID) REFERENCES (DepartmentID)
  08 );
  ```
seed: |
  CREATE TABLE Department (
    DepartmentID INTEGER PRIMARY KEY,
    DepartmentName VARCHAR(40),
    DepartmentLeader VARCHAR(40)
  );
answer: |
  CREATE TABLE Subject (
    SubjectCode VARCHAR(8) PRIMARY KEY,
    SubjectName VARCHAR(40),
    DepartmentID INTEGER,
    FOREIGN KEY (DepartmentID) REFERENCES Department(DepartmentID)
  );
wrong: |
  CREATE TABLE Subject (
    SubjectCode VARCHAR(8),
    SubjectName VARCHAR(40),
    DepartmentID VARCHAR(8)
  );
