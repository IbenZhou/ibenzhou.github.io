title: Total quantity purchased

source: 同构于 2021 冬季 P12 Q6(c)(i)
coverage: SELECT, SUM
schema: |
  PURCHASE(PurchaseID, ItemName, Quantity)
prompt: |
  Return the **total quantity** of items across all purchase records.
seed: |
  CREATE TABLE Purchase (
    PurchaseID INTEGER PRIMARY KEY,
    ItemName VARCHAR(40),
    Quantity INTEGER
  );
  INSERT INTO Purchase VALUES
    (1, 'Exercise book', 30),
    (2, 'Blue pen', 120),
    (3, 'Ruler', 15);
answer: |
  SELECT SUM(Quantity)
  FROM Purchase;
wrong: |
  SELECT COUNT(Quantity)
  FROM Purchase;
check: rows
