title: Link events to their player
marks: 2
difficulty: advanced
source: 同构于 2024 夏季 P11 Q6(c)(i)
coverage: ALTER TABLE, FOREIGN KEY, REFERENCES
schema: |
  PLAYER(PlayerID, PlayerName)
  EVENT(EventID, EventName, EventDate, PlayerID)
prompt: |
  Each event is run by one player, but nothing currently stops an event being recorded
  against a player who does not exist. Using **ALTER TABLE**, make Event.PlayerID a
  **foreign key** that references Player.PlayerID.
seed: |
  CREATE TABLE Player (
    PlayerID INTEGER PRIMARY KEY,
    PlayerName VARCHAR(30)
  );
  CREATE TABLE Event (
    EventID INTEGER PRIMARY KEY,
    EventName VARCHAR(40),
    EventDate DATE,
    PlayerID INTEGER
  );
answer: |
  ALTER TABLE Event ADD FOREIGN KEY (PlayerID) REFERENCES Player(PlayerID);
wrong: |
  ALTER TABLE Event ADD PRIMARY KEY (PlayerID);
check: schema
checktable: Event
