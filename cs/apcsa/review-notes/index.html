How to Use These Notes

  1. Read the unit Overview and the > [!exam] Exam Tip first — they tell you where the points are.
  2. For each topic: read Key Concepts → study the Example Code → attempt the exercises → unfold the reference answers to check your work.
  3. Hard topics (searching, sorting, recursion, 2D arrays, run-time analysis, String manipulation) carry extra exercises — do all of them.
  4. When unsure about a CED statement, cross-check against the official outline: APCSA outline (in APCSA/CED/).
💡 Suggested revision loop

Unit 4 (Data Collections) carries the heaviest exam weight (30–40%). After finishing Units 1–3, loop back to Unit 4’s FRQ-style “write the method” exercises — they mirror AP Exam free-response Questions 3 and 4.
