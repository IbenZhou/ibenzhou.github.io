Unit 2 — Selection and Iteration: Review Notes

Syllabus: AP Computer Science A — Course and Exam Description, Effective Fall 2025
Exam Weight: 25–35% of AP Exam | Class Periods: ~29–31
Topics: 2.1–2.12
AP Classroom: Progress Checks — Part 1 (2.1–2.6) and Part 2 (2.7–2.12)

Overview

Algorithms are composed of three building blocks: sequencing, selection, and iteration. Unit 1 introduced sequencing; this unit focuses on selection and iteration. Selection gives a program the ability to make a decision and respond to that decision using conditional statements, allowing programmers to incorporate choice into their programs — to create games that react to user interactions, to develop simulations that allow for real-world variability, or to filter out irrelevant data. Iteration is a form of repetition that changes the flow of control by repeating a segment of code, and it is represented by while and for loops. Building on the Boolean variables introduced in Unit 1, you will write Boolean expressions with relational and logical operators, including compound expressions and De Morgan’s law. The unit also introduces several standard algorithms that use iteration; knowing these standard algorithms makes solving similar problems easier, as algorithms can be modified or combined to suit new situations.

In this unit you will learn to:

  • Represent patterns and algorithms involving selection and repetition found in everyday life using written language or diagrams
  • Develop code to create Boolean expressions with relational and logical operators and determine the result of these expressions
  • Develop code to represent branching and nested branching logical processes using if statements and determine the result of these processes
  • Compare equivalent Boolean expressions and develop code to compare object references using Boolean expressions
  • Develop code to represent iterative processes using while and for loops and determine the result of these processes
  • Develop code for standard and original algorithms (including string algorithms) and determine the result of these algorithms
  • Represent nested iterative processes and calculate statement execution counts with informal run-time analysis
💡 Exam Tip
  • Trace every loop by hand on paper. Most multiple-choice questions on this unit ask for the result of a code segment, and a careful trace (tracking the loop control variable and each output) is the most reliable way to get them right.
  • Watch for off-by-one errors and loop bounds. Decide carefully whether a loop should use <, <=, > or >=, and whether the control variable starts at 0 or 1; one wrong comparison changes the number of iterations.
  • Do not confuse <mark> with .equals(). </mark> compares primitive values (or object references), while .equals() compares the contents of objects such as String objects. This is one of the most frequently tested traps on the AP Exam.

Topic 2.1 — Algorithms with Selection and Repetition

Key Concepts

Learning Objective [2.1.A] — Represent patterns and algorithms that involve selection and repetition found in everyday life using written language or diagrams.

  • [2.1.A.1]: The building blocks of algorithms include sequencing, selection, and repetition.
  • [2.1.A.2]: Algorithms can contain selection, through decision making, and repetition, via looping.
  • [2.1.A.3]: Selection occurs when a choice of how the execution of an algorithm will proceed is based on a true or false decision.
  • [2.1.A.4]: Repetition is when a process repeats itself until a desired outcome is reached.
  • [2.1.A.5]: The order in which sequencing, selection, and repetition are used contributes to the outcome of the algorithm.
Building block What it does Everyday example
Sequencing Steps are completed one at a time, in order Get a bowl, then pour cereal, then add milk
Selection A true/false decision changes what happens next If the light is red, stop; otherwise, go
Repetition A process repeats until a desired outcome is reached Keep stirring the batter until there are no lumps

Example Code

// The three building blocks used together:
// sequencing (statements run one at a time),
// selection (if statement), and repetition (while loop).
public class Cooking {
    public static void main(String[] args) {
        // Sequencing: these steps run in order.
        int lumps = 10;

        // Repetition: keep stirring while there are lumps.
        while (lumps > 0) {
            lumps = lumps - 1;
        }

        // Selection: decide what to do based on a true/false decision.
        if (lumps == 0) {
            System.out.println("Batter is smooth — done!");
        } else {
            System.out.println("Keep stirring.");
        }
    }
}

📖 参考答案 | Reference Answer

Topic 2.2 — Boolean Expressions

Key Concepts

Learning Objective [2.2.A] — Develop code to create Boolean expressions with relational operators and determine the result of these expressions.

  • [2.2.A.1]: Values can be compared using the relational operators == and != to determine whether the values are the same. With primitive types, this compares the actual primitive values. With reference types, this compares the object references.
  • [2.2.A.2]: Numeric values can be compared using the relational operators <, >, <=, and >= to determine the relationship between the values.
  • [2.2.A.3]: An expression involving relational operators evaluates to a Boolean value (true or false).
Operator Meaning Example Value
<mark> equal to 5 </mark> 5 true
!= not equal to 5 != 5 false
< less than 3 < 2 false
> greater than 3 > 2 true
<= less than or equal to 4 <= 4 true
>= greater than or equal to 6 >= 7 false

Example Code

public class Comparisons {
    public static void main(String[] args) {
        int score = 85;
        double limit = 90.0;

        // Each relational expression evaluates to true or false.
        boolean passed = score >= 60;      // true — 85 is >= 60
        boolean topScore = score > limit;  // false — 85 is not > 90.0
        boolean exact = score == 85;       // true — compares primitive values
        boolean notTop = score != 100;     // true — 85 is not equal to 100

        System.out.println("Passed: " + passed);     // Passed: true
        System.out.println("Top score: " + topScore); // Top score: false
        System.out.println("Exact: " + exact);        // Exact: true
        System.out.println("Not top: " + notTop);     // Not top: true
    }
}

Topic 2.3 — if Statements

Key Concepts

Learning Objective [2.3.A] — Develop code to represent branching logical processes by using selection statements and determine the result of these processes.

  • [2.3.A.1]: Selection statements change the sequential execution of statements.
  • [2.3.A.2]: An if statement is a type of selection statement that affects the flow of control by executing different segments of code based on the value of a Boolean expression.
  • [2.3.A.3]: A one-way selection (if statement) is used when there is a segment of code to execute under a certain condition. In this case, the body is executed only when the Boolean expression is true.
  • [2.3.A.4]: A two-way selection (if-else statement) is used when there are two segments of code — one to be executed when the Boolean expression is true and another segment for when the Boolean expression is false. In this case, the body of the if is executed when the Boolean expression is true, and the body of the else is executed when the Boolean expression is false.

One-way selection (if):

if (Boolean expression) {
    // executed ONLY when the expression is true
}
// execution continues here afterwards

Two-way selection (if-else):

if (Boolean expression) {
    // executed when the expression is true
} else {
    // executed when the expression is false
}

Example Code

public class TemperatureCheck {
    public static void main(String[] args) {
        int temp = 95;

        // One-way selection: the body runs only when temp >= 100.
        if (temp >= 100) {
            System.out.println("Water is boiling.");
        }

        // Two-way selection: exactly one segment runs.
        if (temp >= 32) {
            System.out.println("Above freezing.");
        } else {
            System.out.println("Below freezing.");
        }
    }
}

📖 参考答案 | Reference Answer

(a) A one-way selection executes a segment of code only when its Boolean expression is true; if it is false, nothing in the body runs. A two-way selection has two segments: the body of the if runs when the expression is true, and the body of the else runs when the expression is false — exactly one of the two always runs. [2]

Topic 2.4 — Nested if Statements

Key Concepts

Learning Objective [2.4.A] — Develop code to represent nested branching logical processes and determine the result of these processes.

  • [2.4.A.1]: Nested if statements consist of if, if-else, or if-else-if statements within if, if-else, or if-else-if statements.
  • [2.4.A.2]: The Boolean expression of the inner nested if statement is evaluated only if the Boolean expression of the outer if statement evaluates to true.
  • [2.4.A.3]: A multiway selection (if-else-if) is used when there are a series of expressions with different segments of code for each condition. Multiway selection is performed such that no more than one segment of code is executed, based on the first expression that evaluates to true. If no expression evaluates to true and there is a trailing else statement, then the body of the else is executed.

Structure of nested if:

if (outer condition) {
    if (inner condition) {
        // runs only when outer AND inner are true
    } else {
        // runs only when outer is true AND inner is false
    }
}
// If outer condition is false, the inner if-else never runs.

Structure of multiway if-else-if:

if (expression1) {
    // ...
} else if (expression2) {
    // ...
} else if (expression3) {
    // ...
} else {
    // runs only if NO earlier expression was true
}

Example Code

public class Grade {
    public static void main(String[] args) {
        int score = 87;

        // Multiway selection: at most one branch runs.
        if (score >= 90) {
            System.out.println("A");
        } else if (score >= 80) {
            System.out.println("B");
        } else if (score >= 70) {
            System.out.println("C");
        } else {
            System.out.println("F");
        }
    }
}



// Nested if: the inner condition is checked only when the outer one is true.
public class Login {
    public static void main(String[] args) {
        boolean hasAccount = true;
        String password = "open sesame";

        if (hasAccount) {
            if (password.equals("open sesame")) { // String contents compared
                System.out.println("Welcome back!");
            } else {
                System.out.println("Wrong password.");
            }
        } else {
            System.out.println("Please create an account.");
        }
    }
}

(a) Is the inner Boolean expression a < 20 evaluated? Explain. [2]

(a) No. The inner if’s Boolean expression is evaluated only if the outer expression a > 10 evaluates to true. Since a = 1, the outer expression is false, so the inner expression is never evaluated. [2]

✏️ Exercise 2.4.2 — Tracing an `if-else-if` (4 marks)

Consider:

int n = 55;
if (n >= 100) {
    System.out.println("big");
} else if (n >= 50) {
    System.out.println("medium");
} else if (n >= 0) {
    System.out.println("small");
} else {
    System.out.println("negative");
}

(a) What is the output, and which branch runs? [2]
(b) Explain how the multiway selection guarantees that no more than one segment of code is executed. [2]

📖 参考答案 | Reference Answer

(a) Output is "medium". The first expression 55 >= 100 is false; the second 55 >= 50 is true, so that branch’s body runs and the remaining conditions are not tested. [2]

Topic 2.5 — Compound Boolean Expressions

Key Concepts

Learning Objective [2.5.A] — Develop code to represent compound Boolean expressions and determine the result of these expressions.

  • [2.5.A.1]: Logical operators ! (not), && (and), and || (or) are used with Boolean expressions.
    • The expression !a evaluates to true if a is false and evaluates to false otherwise.
    • The expression a && b evaluates to true if both a and b are true and evaluates to false otherwise.
    • The expression a || b evaluates to true if a is true, b is true, or both are, and evaluates to false otherwise.
    • The order of precedence for evaluating logical operators is ! (not), && (and), then || (or). An expression involving logical operators evaluates to a Boolean value.
  • [2.5.A.2]: Short-circuit evaluation occurs when the result of a logical operation using && or || can be determined by evaluating only the first Boolean expression. In this case, the second Boolean expression is not evaluated.
a b !a a && b a || b
true true false true true
true false false false true
false true true false true
false false true false false

Precedence: ! (highest) → && → || (lowest). So a || b && c means a || (b && c).

Example Code

public class Eligibility {
    public static void main(String[] args) {
        int age = 17;
        boolean hasLicense = true;

        // && (and): both must be true.
        boolean canDrive = (age >= 16) && hasLicense;   // true
        System.out.println("Can drive: " + canDrive);

        int temp = 95;
        // || (or): at least one must be true.
        boolean isExtreme = (temp >= 100) || (temp <= 0); // false
        System.out.println("Extreme: " + isExtreme);

        // ! (not): flips the value.
        boolean notBusy = !hasLicense;   // false
        System.out.println("Not busy: " + notBusy);
    }
}

Short-Circuit Evaluation Example

public class ShortCircuit {
    public static void main(String[] args) {
        String word = null;

        // With ||, since word == null is true, the RIGHT side is NOT evaluated.
        if (word <mark> null || word.length() </mark> 0) {
            System.out.println("Empty or null.");   // runs safely
        }

        // Danger: this order evaluates word.length() first and crashes
        // with a NullPointerException because word is null.
        // if (word.length() <mark> 0 || word </mark> null) { ... }  // BAD — crashes
    }
}

✏️ Exercise 2.5.2 — Short-Circuit Evaluation (4 marks)

Consider int x = 5;. What is printed by each segment, and why? [4]

Topic 2.6 — Comparing Boolean Expressions

Key Concepts

Learning Objective [2.6.A] — Compare equivalent Boolean expressions.

  • [2.6.A.1]: Two Boolean expressions are equivalent if they evaluate to the same value in all cases. Truth tables can be used to prove Boolean expressions are equivalent.
  • [2.6.A.2]: De Morgan’s law can be applied to Boolean expressions to create equivalent Boolean expressions. Under De Morgan’s law, the Boolean expression !(a && b) is equivalent to !a || !b, and the Boolean expression !(a || b) is equivalent to !a && !b.

Learning Objective [2.6.B] — Develop code to compare object references using Boolean expressions and determine the result of these expressions.

  • [2.6.B.1]: Two different variables can hold references to the same object. Object references can be compared using == and !=.
  • [2.6.B.2]: An object reference can be compared with null, using == or !=, to determine if the reference actually references an object.
  • [2.6.B.3]: Classes often define their own equals method, which can be used to specify the criteria for equivalency for two objects of the class. The equivalency of two objects is most often determined using attributes from the two objects.
    • Exclusion: Overriding the equals method is outside the scope of the AP Computer Science A course and exam.

De Morgan’s law:

  • !(a && b) is equivalent to !a || !b
  • !(a || b) is equivalent to !a && !b
a b !(a && b) !a || !b !(a || b) !a && !b
T T F F F F
T F T T F F
F T T T F F
F F T T T T

Example Code

public class ObjectCompare {
    public static void main(String[] args) {
        String a = "java";
        String b = "java";      // may or may not be the same object as a
        String c = new String("java"); // a different object with same contents

        // == on reference types compares REFERENCES, not contents:
        boolean sameObject = (a == c);          // false (different objects)
        boolean nullSafe = (a != null);         // true — a references an object

        // equals() compares the contents of the String objects:
        boolean sameContents = a.equals(c);     // true — both hold "java"

        System.out.println("Same object: " + sameObject);
        System.out.println("Not null: " + nullSafe);
        System.out.println("Same contents: " + sameContents);
    }
}



// null check: determine whether a reference actually references an object.
public class NullCheck {
    public static void main(String[] args) {
        String word = null;
        if (word == null) {
            System.out.println("No object yet.");
        } else {
            System.out.println(word.length());  // safe: word references an object
        }
    }
}

Topic 2.7 — while Loops

Key Concepts

Learning Objective [2.7.A] — Identify when an iterative process is required to achieve a desired result.

  • [2.7.A.1]: Iteration is a form of repetition. Iteration statements change the flow of control by repeating a segment of code zero or more times as long as the Boolean expression controlling the loop evaluates to true.
  • [2.7.A.2]: An infinite loop occurs when the Boolean expression in an iterative statement always evaluates to true.
  • [2.7.A.3]: The loop body of an iterative statement will not execute if the Boolean expression initially evaluates to false.
  • [2.7.A.4]: Off-by-one errors occur when the iteration statement loops one time too many or one time too few.

Learning Objective [2.7.B] — Develop code to represent iterative processes using while loops and determine the result of these processes.

  • [2.7.B.1]: A while loop is a type of iterative statement. In while loops, the Boolean expression is evaluated before each iteration of the loop body, including the first. When the expression evaluates to true, the loop body is executed. This continues until the Boolean expression evaluates to false, whereupon the iteration terminates.

Structure:

while (Boolean expression) {
    // loop body — repeated while the expression is true
}
// execution continues here when the expression becomes false

Example Code

public class Countdown {
    public static void main(String[] args) {
        int count = 5;

        // The Boolean expression is checked BEFORE each iteration.
        while (count > 0) {
            System.out.println(count);
            count = count - 1;      // progress toward making the condition false
        }
        System.out.println("Blast off!");  // printed once the loop ends
    }
}



// The body does not execute when the condition is initially false.
public class ZeroIterations {
    public static void main(String[] args) {
        int n = 3;
        while (n < 0) {              // 3 < 0 is false immediately
            System.out.println("inside");
            n = n - 1;
        }
        System.out.println("done");  // only "done" is printed
    }
}



// DANGER: an infinite loop — the Boolean expression is always true.
public class Infinite {
    public static void main(String[] args) {
        int x = 1;
        while (x > 0) {              // x never becomes <= 0
            x = x + 1;               // so this loop never terminates!
        }
    }
}

Topic 2.8 — for Loops

Key Concepts

Learning Objective [2.8.A] — Develop code to represent iterative processes using for loops and determine the result of these processes.

  • [2.8.A.1]: A for loop is a type of iterative statement. There are three parts in a for loop header: the initialization, the Boolean expression, and the update.
  • [2.8.A.2]: In a for loop, the initialization statement is only executed once before the first Boolean expression evaluation. The variable being initialized is referred to as a loop control variable. The Boolean expression is evaluated immediately after the loop control variable is initialized and then following each execution of the increment statement until it is false. In each iteration, the update is executed after the entire loop body is executed and before the Boolean expression is evaluated again.
  • [2.8.A.3]: A for loop can be rewritten into an equivalent while loop (and vice versa).

Structure:

for (initialization; Boolean expression; update) {
    // loop body
}

Execution order:

  1. initialization runs once (creates the loop control variable).
  2. Evaluate the Boolean expression — if false, the loop ends.
  3. Execute the loop body.
  4. Execute the update.
  5. Go back to step 2.

for loop → equivalent while loop:

// for version:
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

// while version:
int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}

Example Code

public class ForLoopDemo {
    public static void main(String[] args) {
        // initialization: int i = 0 (runs once)
        // Boolean expression: i < 5 (checked before each iteration)
        // update: i++ (runs after each full body)
        for (int i = 0; i < 5; i++) {
            System.out.println("Iteration " + i);
        }

        // Counting down:
        for (int j = 10; j >= 0; j -= 2) {
            System.out.println(j);   // 10 8 6 4 2 0
        }
    }
}

Topic 2.9 — Implementing Selection and Iteration Algorithms

Key Concepts

Learning Objective [2.9.A] — Develop code for standard and original algorithms (without data structures) and determine the result of these algorithms.

  • [2.9.A.1]: There are standard algorithms to:
    • identify if an integer is or is not evenly divisible by another integer
    • identify the individual digits in an integer
    • determine the frequency with which a specific criterion is met
    • determine a minimum or maximum value
    • compute a sum or average
Standard algorithm Idea Key technique
Evenly divisible a % b == 0 means a is evenly divisible by b Remainder operator %
Individual digits Repeatedly take n % 10 and n / 10 Digit extraction
Frequency / counting Increment a counter when a criterion is met Counter variable
Minimum / maximum Compare each value with the best so far Sentinel-style tracker
Sum / average Accumulate values, divide by count Running total

Example Code

public class StandardAlgorithms {
    public static void main(String[] args) {
        // 1. Evenly divisible: is 15 evenly divisible by 5?
        int n = 15, divisor = 5;
        if (n % divisor == 0) {
            System.out.println(n + " is divisible by " + divisor);
        }

        // 2. Identify the individual digits of 273 (right to left: 3, 7, 2).
        int num = 273;
        while (num > 0) {
            int digit = num % 10;   // last digit
            System.out.println(digit);
            num = num / 10;         // drop the last digit
        }
    }
}



public class MoreAlgorithms {
    public static void main(String[] args) {
        int[] values = {7, 3, 9, 2, 6};   // for loop over an array

        // 3. Frequency: count how many are even.
        int countEven = 0;
        for (int i = 0; i < values.length; i++) {
            if (values[i] % 2 == 0) {
                countEven++;
            }
        }
        System.out.println("Even count: " + countEven);   // 2

        // 4. Maximum value.
        int max = values[0];
        for (int i = 1; i < values.length; i++) {
            if (values[i] > max) {
                max = values[i];
            }
        }
        System.out.println("Max: " + max);   // 9

        // 5. Sum and average.
        int sum = 0;
        for (int i = 0; i < values.length; i++) {
            sum += values[i];
        }
        double average = (double) sum / values.length;
        System.out.println("Sum: " + sum + " Average: " + average);
    }
}

Topic 2.10 — Implementing String Algorithms

Key Concepts

Learning Objective [2.10.A] — Develop code for standard and original algorithms that involve strings and determine the result of these algorithms.

  • [2.10.A.1]: There are standard string algorithms to:
    • find if one or more substrings have a particular property
    • determine the number of substrings that meet specific criteria
    • create a new string with the characters reversed
String algorithm Approach
Find a property in a substring Loop over indices; use charAt, substring, indexOf
Count substrings meeting criteria Counter variable; check each character or substring
Reverse a string Build a new string from last character to first

AP Quick Reference String methods used in this unit: String substring(int from, int to), int length(), String substring(int from), int indexOf(String str), boolean equals(String other), int compareTo(String other), char charAt(int index).

Example Code

public class StringAlgorithms {
    public static void main(String[] args) {
        String word = "banana";

        // 1. Find a property: does the word contain the letter 'a'?
        boolean hasA = word.indexOf("a") != -1;   // indexOf returns -1 if absent
        System.out.println("Contains 'a': " + hasA);

        // 2. Count substrings meeting a criterion:
        //    how many characters are vowels (a, e, i, o, u)?
        int vowelCount = 0;
        for (int i = 0; i < word.length(); i++) {
            String ch = word.substring(i, i + 1);   // one-character substring
            if (ch.equals("a") || ch.equals("e") || ch.equals("i")
                || ch.equals("o") || ch.equals("u")) {
                vowelCount++;
            }
        }
        System.out.println("Vowel count: " + vowelCount);   // 3

        // 3. Create a new string with the characters reversed.
        String reversed = "";
        for (int i = word.length() - 1; i >= 0; i--) {
            reversed += word.substring(i, i + 1);
        }
        System.out.println("Reversed: " + reversed);   // ananab
    }
}

Topic 2.11 — Nested Iteration

Key Concepts

Learning Objective [2.11.A] — Develop code to represent nested iterative processes and determine the result of these processes.

  • [2.11.A.1]: Nested iteration statements are iteration statements that appear in the body of another iteration statement. When a loop is nested inside another loop, the inner loop must complete all its iterations before the outer loop can continue to its next iteration.

Key idea: For each iteration of the outer loop, the inner loop runs from start to finish. If the outer loop runs m times and the inner loop runs n times per outer iteration, the inner body executes m × n times total.

Example Code

public class NestedLoopDemo {
    public static void main(String[] args) {
        // For each outer iteration (row), the inner loop (columns)
        // runs completely before the outer loop moves on.
        for (int row = 1; row <= 3; row++) {
            for (int col = 1; col <= 3; col++) {
                System.out.print(row + "," + col + " ");
            }
            System.out.println();   // move to the next row
        }
    }
}

Output:

1,1 1,2 1,3
2,1 2,2 2,3
3,1 3,2 3,3

Topic 2.12 — Informal Run-Time Analysis

Key Concepts

Learning Objective [2.12.A] — Calculate statement execution counts and informal run-time comparison of iterative statements.

  • [2.12.A.1]: A statement execution count indicates the number of times a statement is executed by the program. Statement execution counts are often calculated informally through tracing and analysis of the iterative statements.

Approach to counting:

  1. Identify how many times each loop iterates.
  2. Multiply counts for nested loops (inner body executes outer-runs × inner-runs times).
  3. Compare two code segments by their execution counts — the one with fewer total statement executions generally runs faster informally.

Example Code

public class ExecutionCounts {
    public static void main(String[] args) {
        // Single loop: the body runs exactly n times.
        int n = 5;
        int sum = 0;
        for (int i = 0; i < n; i++) {
            sum += i;            // executed n = 5 times
        }

        // Nested loop: the inner body runs row * col times.
        int total = 0;
        for (int row = 0; row < n; row++) {        // runs n = 5 times
            for (int col = 0; col < n; col++) {    // runs n times per outer
                total++;                           // executed n * n = 25 times
            }
        }
    }
}

Comparing Two Segments Informally

// Segment A: fixed inner bound — inner body runs 3 * 3 = 9 times.
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        System.out.println(i * j);
    }
}

// Segment B: variable inner bound — inner body runs 3 * n times.
int n = 10;
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < n; j++) {
        System.out.println(i * j);
    }
}
