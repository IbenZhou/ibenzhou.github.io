About These Notes

These review notes follow the official AP CSP course framework, organized by the five Big Ideas. Each file covers the specific exam requirements (Learning Objectives & Essential Knowledge), explains every knowledge point, and provides practice exercises with foldable reference answers in Obsidian callout format.

How to Use These Notes

  1. Read the Overview of each big idea first to get the big picture and the exam weight.
  2. Study Key Concepts — every Learning Objective and Essential Knowledge statement from the CED is included verbatim.
  3. Try the exercises after each knowledge point — the [!exercise] callouts show the question; click the [!example]- callout below to reveal the foldable reference answer with mark allocations.
  4. Before the exam: re-trace every pseudocode example by hand, and re-do the exercises from the hardest topics (3.10 Lists, 3.11 Binary Search, 3.17 Algorithmic Efficiency, 3.18 Undecidable Problems, 5.6 Safe Computing).
